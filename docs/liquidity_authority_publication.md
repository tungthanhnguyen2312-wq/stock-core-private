# Liquidity authority publication disposition

`AUTHORITY_CLOSURE_LIQUIDITY_FOUNDATION_V1` is published as code, hermetic tests,
source schemas, and a research-use contract.  It intentionally excludes every retained
official-exchange response body and every response-derived fixture.

## Publication boundary

The HOSE and HNX routes are first-party sources for the stated observations, but public
reachability is not a redistribution licence.  HNX describes fee-based information products
and its published materials reserve copying without permission.  No equivalently explicit
permission to redistribute the retrieved response bytes was established for this review.

Accordingly, public Git contains only:

- request-shape and schema code;
- raw-response hashes, counts, and provenance concepts when an operator builds a private
  evidence artifact;
- derived rules and capability states; and
- hermetic, synthetic test fixtures.

Raw bodies, HTML tables, JSON API responses, request ledgers containing response content, and
response-derived market-value datasets remain local/private evidence.  A future publication
requires an explicit exchange redistribution grant or a fresh legal review.

## Research boundary

For an independently retained, exact official row, current-session components are measurable
in shares and VND.  The board-unit contract is per exchange: no board qualification is
generalized between HOSE, HNX, and UPCoM.  Official trailing series make the scoped
`ADTV20_MATCHED_ALL_VND` usable only where every governed session is present; ADV remains
as-traded and not corporate-action normalized.

This does not open execution capacity, position sizing, or point-in-time backtests.  Those
remain blocked by missing policy/model and knowledge-time inputs described in
`docs/liquidity_authority_contract.md`.
