## Product choice and contract

Existing decision-intelligence closure deferred the local CLI. Extend that
capability rather than relocate another package or open another decision engine.
The released feedback reader also reproducibly returns rows from an object
missing its final brace. A partial artifact can therefore become a complete
review. The corrective checks the complete root and suffix, strict commas,
duplicate keys, object records and finite numeric tokens. UTF8 text IO preserves
characters at refill boundaries. Existing ObjectStream bounds individual tokens
and records to 16 MiB; large non-record metadata is traversed structurally rather
than decoded as a whole container. Metadata depth is bounded at 128. The iterator
must be exhausted before a result is emitted. Any later syntax error invalidates
the entire CLI report. The calibration reducer and all numerical policies remain.

Owner entrypoints:

```text
python stocklookup.py research coverage --session YYYY-MM-DD --universe <path> --technical <path> --valuation <path> --intelligence <path> --events <path> --ticker HPG
python stocklookup.py research calibration --feedback <path>
```

stocklookup.ps1 research accepts the same arguments. Coverage accepts optional
--panel pointing at an existing historical_temporal_research_panel/v1 projection;
it does not search runtime stores. Repeated --ticker changes only the focus display;
the full 1,683 universe denominator is always validated. A different denominator
requires a separate existing-contract rebaseline, never silent shrinkage.
Each coverage artifact must declare its own correct contract and exact requested
session (the universe uses input_candidates.resolved_completed_session; valuation
uses valuation_session; event context uses research_session). Bad dates, future
panel rows, malformed records and session substitutions fail. Not supplying a
panel means HISTORICAL_PANEL_NOT_SUPPLIED, not absence of real historical evidence.

stdout JSON only: exit0 AVAILABLE report or exit2 UNAVAILABLE reason. No output
path, latest selection, provider call, workbook or private portfolio input. Source
hashes before and after inspection detect modification during the call. References
contain basenames and SHA256 only; these prove byte selection, not source trust,
knowledge eligibility or immutable operational binding. Errors omit host paths and
source bodies. These are current research / retained outcome views, never PIT use.
The explicit panel is a supplied projection, not a newly qualified source.
