# Audited annual exact-field research context

`audited_annual_exact_field_context/v1` uses the existing official overlay and
`reviewed_interim_canonical_ingress/v2`; it creates no valuation authority or new registry.
Explicit opt-in admits only audited consolidated FY2025 VND facts with document-backed
assurance and the existing exact label, period, unit, geometry and numeric gates.
Default interim ingress remains unchanged. Rows carry `AUDITED_ANNUAL_FIELD` and
`AUDITED_ANNUAL_CONTEXT_ONLY`; missing or inconsistent markers fail session projection.

The source facts are historical context. They do not replace the pinned annual baseline,
legacy citations, provider observations, shares or any valuation input. No TTM,
annualization, currency conversion or normalized earnings is calculated. All downstream
consumers preserve `NOT_PERMITTED_AUDITED_ANNUAL_CONTEXT` through their existing context lane.

does not change the currency of its USD interim report.

Literal semantic headers may use the same TSV source line within the already bounded
physical header group when glyph baselines split words. The exact token order, positions
and words are preserved; native PDF grouping is unchanged. Different source lines,
damaged letters, ambiguous digits and competing header spans remain blocked.

Acquisition preserves old PDF bytes and knowledge receipts. `--refresh-indexes` refreshes
only approved index pages; unchanged hashes leave the manifest unchanged. Actual HTTP
redirect/retry requests share the request cap and declared interval, and direct annual
documents share the two-document issuer cap. Literal index href, URL and SHA bind discovery.
Native response retention stamps its actual observation time. The first campaign batch
receipt predates individual responses; a later qualification observation conservatively
bounds annual knowledge instead of rewriting that receipt or inferring publication.
