# Official financial representation

Contract `official_financial_representation/v1`. Machine state for the milestone
is `OFFICIAL_FINANCIAL_DOCUMENT_REPRESENTATION_RECOVERY_V1`.

`SOURCE_DOCUMENT_IDENTITY` is the filing: issuer, reporting period, scope,
assurance, and statement family. `REPRESENTATION_IDENTITY` is one copy: class,
SHA-256, and whether the bytes have a native text layer.

An alternate copy is the same filing only with an official identity proof:
an explicit cross-link, the same publication, an official language counterpart,
an official exchange mirror, or the same title, date, and reference. Equal
looking totals are not proof. A different period, a different scope, or an
unofficial mirror is not the same filing.

Representation class describes machine readability and the official
relationship. It does not rank source authority. Two official copies of one
filing have equal source authority.

Two outputs of the same OCR engine on the same pixels are one representation.
A native-text PDF, an official HTML statement, or an official spreadsheet can
be independent. An image-only language counterpart is official and is not
independently parseable. This milestone does not OCR that counterpart and does
not repair the original scan.

A qualified value, when one exists, is cited from the representation that
supplied it. A true numeric conflict has no winner. Recovered facts use the
knowledge time of the assessment and stay out of completed October 7 records.
They do not change strict share continuity or strict valuation.

The fixed five-fact cohort found three image-only language counterparts and
recovered zero facts. Disposition:
`OFFICIAL_REPRESENTATION_BOTTLENECK_CONFIRMED`.
Future acquisition may prefer a native-text, HTML, or spreadsheet copy only
when the same official page explicitly lists it beside the scan. This cohort
did not list such a copy, so the discovery path is unchanged.
