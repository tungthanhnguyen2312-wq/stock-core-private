## Financial period label meaning

`_observed_period_range` takes a **lexicographic maximum of retained feature period
labels** across the whole engine. It never derives a reporting-calendar context,
publication cutoff, common ticker period, or most recent completed calendar report.
2026-Q4 comes from ITD/TCH gross/net/PBT margin feature labels in retained KBS
research inputs known by the pinned semantics timestamp 2026-09-05, before October 9.
The existing fundamental consumption rule reports
NON_CALENDAR_FISCAL_PERIOD_KNOWN_BY_SESSION with calendar period
UNRESOLVED_NO_GOVERNED_FISCAL_YEAR_REGISTRY; those unresolved periods never vote
as current calendar evidence. No governed fiscal-year conversion or publication
time is available. This corrective does not change any engine values or fitness.

New session wrappers expose `latest_observed_financial_period_label` and
`financial_evidence_period_label_context`: explicit label semantics, false
publication-cutoff/reporting-calendar flags, null published-calendar evidence
period and per-feature observations using the existing fiscal rule/knowledge
time. `financial_evidence_as_of_period` remains a documented legacy alias for
the raw maximum label so old readers remain compatible; it is not a published
calendar-Q4 claim. Brief projects this metadata and clarifies its note. Old
wrappers lacking observation metadata retain an empty observation list rather
than fabricated lineage. Historical artifacts remain unchanged.
