# Reported earnings component context

`reported_earnings_component_context/v1` extends the existing reviewed interim overlay
and explicit-session projection. It admits only the reported income-statement line 21
investment-property disposal result when the literal row label contains both disposal
and investment-property identity. Exact geometry, unit, consolidated scope, assurance,
period, citation and knowledge-time gates remain required. No OCR letter or digit repair.

An already qualified physical label is preserved. For incomplete label identity only,
TSV label ownership runs from the exact code's source hierarchy line up to, excluding,
the next visible code-column line in the same block and paragraph. Only label selection
uses this window; amount cells keep physical midpoint bounds, including malformed neighbours.
Both-sided labels and ambiguous ownership fail closed. Literal token orders and label bounds
are retained in citation lineage. No ticker-specific extraction rules.

The component is context only, excluded from legacy citations and valuation input use.
A qualified, current, nonzero result sets `NON_RECURRING_COMPONENT_PRESENT_OR_POSSIBLE`.
Recurrence stays `UNKNOWN`: a reported disposal result does not establish a one-off adjustment.
No normalized EPS, annualization, TTM, score, threshold or recommendation follows.
Missing, zero, stale, conflicted, unqualified or post-cutoff evidence leaves quality `UNKNOWN`;
absence never proves clean earnings. Existing packet and AI consumers preserve this context.

The same component contract also admits an audited consolidated FY2025 VND row when its
period stays explicit. Reviewed interim and audited annual components are different facts.
An annual component uses `AUDITED_ANNUAL_COMPONENT_CONTEXT_ONLY` and does not become a
current interim field, an annual exact-field valuation input, or normalized earnings.
FPT FY2025 cash-flow line 03 is the literal English label `Provisions`, amount
651,406,282,654 VND, page 13 of the retained audited consolidated statements.
Its semantic type is `PROVISION_COMPONENT_REPORTED`. The status
`NON_RECURRING_COMPONENT_PRESENT_OR_POSSIBLE` means a quality component is present;
it does not classify the provision as one-time. Recurrence stays `UNKNOWN`.
Historical earnings-quality context carries `FY2025`. Current earnings-quality context
does not absorb it. Completed October 7 projections exclude it by knowledge time.

Superscript digits such as `²` are a Tesseract 5.5 `vie+eng` PSM 6 reading of ordinary
digit glyphs on image-only pages. Unicode NFKC maps those code points to ASCII digits.
Applying that fold to labels, line codes, units, dates, or year headers is not authorized.
`²0²5` is not a qualified year token, and `Số cudi ky` is not `Số cuối kỳ`.
A numeric fold may be considered only after row and column identity are already literal
and an independent confirmation exists. No retained cell in the five-cell cohort has that
confirmation, so the disposition is `SOURCE_FAITHFUL_NORMALIZATION_NOT_YET_PROVABLE`.
The amount parser still rejects the raw superscript token. No normalized value is emitted.
