# Corporate currency Daily rollforward

Canonical Daily owns one bounded corporate rollforward after a valid exact-session
snapshot. A verified successful acquisition on the current Vietnam civil date is
reused with no fetch. Missing materialization is recovered offline. Corrupt retained
success fails locally without refetch. Prior descriptive reuse requires an explicit
maximum-age policy; the canonical caller does not invent one.

The immutable result carries captured current-context bytes and a separate frozen
market selection. New-session optional event/universe inputs are copied to immutable
content-addressed paths before downstream materialization. Registration consumes
that mapping, including explicit absence, rather than rediscovering the latest file.
Completed sessions retain their actual optional lock; missing historical optionals
remain absent. Source hashes are verified on registration and reuse.

The existing Integrated Decision evaluation time is session 15:00 Vietnam time.
New corporate market inputs must be known by that cutoff. Acquisition start is not
retrieval-time proof: each retained event's timezone-aware observation and any
explicit publication timestamp must satisfy the cutoff. Missing/naive/malformed
observation times fail closed. Current knowledge may be later; it never repairs T0.
This is the existing decision boundary, not a new exchange-close claim or PIT promotion.

Current knowledge is retained separately by actual knowledge civil date and content
identity. It carries the captured official context, independently built existing
Corporate Intelligence/R4 explanations when the exact universe lineage is available,
the refresh receipt, and explicit non-voting/historical-use prohibitions. Supplemental
latest evidence is not independently reintroduced into canonical frozen corporate
consumers.

Post-handoff current presentation receives this overlay explicitly. The dashboard
workspace gets separate per-ticker explanatory context and a new content identity.
A current-knowledge brief is copied from the exact sealed brief into a separate
knowledge-date namespace. Frozen source identities, decision identities, posture,
prospective cases and original brief/evidence bytes are unchanged. Historical
compatibility never supplies the current overlay. No downstream discovery selects
an alternative current corporate context.

Corporate refresh failure remains component-local. It is retained in the receipt;
unrelated market, technical, fundamental and valuation paths continue. No voting,
RAW, PIT, universe, factor, sizing or execution authority is granted by this wiring.

Validation uses hermetic injected canonical Daily boundaries and retained PR #37
evidence. The retained coverage figures are regression facts, not coverage targets.
