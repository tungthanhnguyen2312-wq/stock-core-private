# Currency-preserving reviewed interim context

Existing retained overlay rows may carry exact reviewed/audited consolidated interim
income fields in VND or USD. Every existing document, assurance, row/column, scale,
period, citation and knowledge-time qualification remains required. USD is admitted
only for revenue, consolidated net income and parent-attributable net income.

Amounts are normalized within their stated currency only. No exchange rate or VND
equivalent is inferred. USD rows explicitly declare SOURCE_CURRENCY_CONTEXT_ONLY and
remain excluded from the existing VND canonical-citation/valuation input lane.
Session projection preserves USD and sets valuation use NOT_PERMITTED_FOREIGN_CURRENCY_CONTEXT.
No annualization, TTM, share qualification or ticker-wide authority promotion follows.

The existing explicit session/identity path carries these fields to research consumers.
Unknown currencies, incomplete semantics, conflicts and post-cutoff knowledge fail closed.
Completed sessions, historical artifacts and the Financial V2 input pin are unchanged.
