# Scenario Analysis Contract

Schema/engine version `1.0.0`. The engine emits deterministic structured Facts, Data Warnings, Inferences, and Hypotheses without turning one class into another. Bear/base/bull scenarios are conditional records, never probabilities, target prices, or recommendations.

Current technical observations may support timing inferences only when daily-market and technical freshness are actionable and market/technical readiness is `ready`. Stale, blocked, malformed, partial, and unknown inputs remain visible and fail closed. Corporate Events partial 50-row coverage never establishes event absence or lifecycle; Corporate Intelligence preserves producer completeness/comparability gates; unavailable valuation/fundamental outputs are not evidence.

Producer supplies scenarios from the evidence-gated opportunity dimensions. Only qualified financial/valuation facts and current technical facts are attached; missing catalyst evidence remains unknown rather than becoming a narrative.


## R5 conditional valuation cases — 2026-10-01

The canonical `current_research_intrinsic_scenario/v1` projection extends the existing intrinsic engine. BEAR / BASE / BULL name conditional valuation assumption sets. BASE is a reference set and never “most likely”; none of the cases has a probability. Read every number as: IF this governed assumption set holds, this method returns this model value.

CONSERVATIVE / BASE / SPECULATIVE remain research-condition axes under their existing contract. Legacy qualitative scenario outputs and expectations research remain unchanged. A shared spelling of BASE does not connect the two contracts.

Every valuation case has its own method-bound assumption-set and content identity, source/input lineage, readiness, limitations and invalidation conditions. Method ranges and reverse implications stay separate; no blended fair value, consensus target, automatic recommendation, upside threshold or policy retune is introduced. FCFF sensitivity crosses only existing explicitly governed coordinates; absent rates do not create a grid.

R4 `forward_driver_context/v1` binds explanatory source/event identities, dates, status and fitness. It can identify evidence requiring review before an explicit governed assumption revision. It cannot adjust growth, margin, WACC, terminal growth or any number from an event label. PLANNED != EXECUTED and record_date != ex_date remain explicit; missing dates and direction stay missing. No R4 driver is qualified as a forecast merely because it has provenance.

Absent intrinsic coverage blocks dependent model uses only. Relative valuation, Current Research fitness and research_action_posture remain governed by their existing inputs. Retained October 1 acceptance has zero changed decision identities, postures or unexplained analytical fields, with source bytes unchanged.
